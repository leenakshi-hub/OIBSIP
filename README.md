# Web Development & Designing Internship

## Overview

This repository contains my internship projects completed under the **Web Development & Designing** track. The projects demonstrate my understanding of front-end web development using **HTML5, CSS3, and Vanilla JavaScript**, along with concepts such as DOM manipulation, responsive design, local storage, and client-side authentication.

As per the internship guidelines, I completed the following projects:

### Projects Included

1. **Calculator**
   - A responsive calculator that performs basic arithmetic operations.
   - Built using HTML, CSS Grid, and JavaScript without using `eval()`.

2. **Tribute Page**
   - A responsive tribute website dedicated to a renowned personality.
   - Includes biography, achievements, timeline, and inspirational quote.

3. **To-Do Web App**
   - A task management application with add, edit, delete, and complete features.
   - Uses Local Storage to save tasks even after refreshing the page.

4. **Login Authentication System**
   - A client-side authentication system with user registration, login, password validation, session management, and a protected dashboard.
   - Passwords are securely stored using SHA-256 hashing.
