# Tribute Page

## Objective
Create a responsive tribute page dedicated to a famous personality using HTML and CSS.

## Technologies Used
- HTML5
- CSS3

## Features
- Attractive hero section
- Subject image
- Biography section
- Timeline of achievements
- Inspirational quote
- Multiple background colors
- Different font styles
- Responsive design

## Project Structure
```
Tribute-Page/
│── index.html
│── style.css
│── README.md
```

## How to Run
1. Download or clone the project.
2. Open the folder.
3. Run `index.html` in any browser.
