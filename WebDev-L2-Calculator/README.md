# Calculator Web App

## Objective
Build a browser-based calculator using HTML, CSS, and JavaScript without using `eval()`. The calculator performs basic arithmetic operations with a clean and responsive interface.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Display screen for input and results
- Number buttons (0–9)
- Decimal point support
- Addition, Subtraction, Multiplication, Division
- Equals button
- Clear (C) button
- Backspace/Delete button
- Prevents division by zero
- Supports operator chaining
- Responsive layout using CSS Grid
- Event listeners used instead of inline JavaScript

## Project Structure
```
Calculator/
│── index.html
│── style.css
│── script.js
│── README.md
```

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
